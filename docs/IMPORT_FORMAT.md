# ملف الجامعة الكامل: الصيغة وبرومبت الاستخراج

## المسار المعتمد

1. اختر PDF لجامعة واحدة، أو حدّد الجامعة المقصودة داخل دليل متعدد الجامعات.
2. افتح محادثة جديدة، وأرفق الـPDF، والصق البرومبت أدناه. الناتج ملف JSON.
3. في الإدارة افتح **الجامعات ← أيقونة المجلد بجانب الجامعة ← استيراد ملف الجامعة**، ثم ارفع الملف.
4. راجع المعاينة: جديد / تحديث / غير مؤكد / مطابق / في السلة / يحتاج تصحيح. اختر ما تعتمده.
5. اضغط «اعتماد». الجديد يُحفظ **مسودة**، ولا يُنشر شيء بالرفع.
6. راجع المحتوى من تبويبات مساحة العمل، ثم اضغط «نشر الجامعة ومحتواها».

> لا يمكن رفع PDF مباشرة إلى الموقع. المدعوم هو JSON فقط، والاستخراج من الـPDF يتم في محادثة منفصلة.

## الصيغة `muwajjah-university-v2`

```json
{
  "format": "muwajjah-university-v2",
  "university": {
    "name": "جامعة أم القرى",
    "city": "مكة المكرمة",
    "region": "منطقة مكة المكرمة",
    "type": "حكومية",
    "description": "نبذة مختصرة كما وردت",
    "housing_status": "available | limited | unavailable | unknown",
    "housing_note": "",
    "website_url": "https://..."
  },
  "programs": [
    { "name": "الهندسة الكهربائية", "college": "كلية الهندسة", "degree": "بكالوريوس",
      "gender": "طلاب", "campus": "العابدية", "admission_route": "", "page": 14 }
  ],
  "tracks": [
    { "name": "المسار العلمي", "academic_year": "1447", "gender": "",
      "school_weight": 30, "aptitude_weight": 30, "achievement_weight": 40,
      "requirements": "", "page": 9 },
    { "name": "القبول عبر SAT", "academic_year": "",
      "school_weight": 0, "aptitude_weight": 0, "achievement_weight": 0,
      "requirements": "الشروط كما وردت", "page": 10 }
  ],
  "sections": [
    { "title": "التصنيف", "content": "النص كما ورد مع الجهة والسنة", "page": 3 }
  ],
  "cutoffs": [
    { "program_name": "الطب والجراحة", "academic_year": "1446", "gender": "", "ratio": 96.4, "page": 20 }
  ],
  "source": { "url": "رابط الدليل إن وجد" },
  "uncertain": [ { "note": "معلومة غير واضحة في المصدر", "page": 23 } ]
}
```

### قواعد يطبقها المستورد

| القاعدة | ما يحدث |
| --- | --- |
| `id`, `university_id`, `published`, `deleted_at`, `publication_excluded`, وحقول الصلاحيات | تُتجاهل مع تنبيه، ولا يمنح الملف أي سلطة. |
| قيمة فارغة في الملف | لا تمسح قيمة محفوظة أبدًا. |
| «ملء الفارغ فقط» (الافتراضي) | يكتب فقط في الحقول الفارغة لدى السجل الموجود. |
| «استبدال القيم المختلفة» | يستبدل القيم المختلفة غير الفارغة، بعد ظهورها في المعاينة. |
| تخصصان يختلفان في الدرجة أو المقر أو الفئة | يبقيان سجلين منفصلين. |
| مسار مجموع أوزانه ليس 100 ولا 0 | «يحتاج تصحيح»، ولا يُحفظ. |
| مسار نصي (أوزانه صفر) بلا شروط | «يحتاج تصحيح». |
| مسار نصي بلا سنة | يُقبل في المعاينة، لكن حفظه يحتاج تطبيق `database/002_textual_tracks.sql`. |
| نسبة بلا سنة صريحة | «يحتاج تصحيح». لا تُنسب إلى سنة مفترضة. |
| سجل يطابق سجلًا في السلة | «في السلة»، ويُترك كما هو ولا يُعاد. |
| `"uncertain": true` على سجل | «غير مؤكد»، ولا يُحدّد للحفظ تلقائيًا. |
| قائمة `uncertain` العامة | تُعرض للمراجعة ولا تُحفظ. |
| `page` | يظهر في المعاينة فقط، ولا يُخزّن في القاعدة. |
| تاريخ المراجعة | لا يُملأ تلقائيًا. تكتبه أنت فقط إن راجعت المعلومات بنفسك. |
| إعادة المحاولة بعد انقطاع | ما حُفظ يصبح «مطابق»، فلا يتكرر. |

### توافق الصيغة القديمة v1

يقبل المستورد `muwajjah-university-v1` والملفات التي لا تحدد `format`، ويحوّل الأسماء الشائعة. هذه المفاتيح اختُبرت في `tests/bundle.test.ts`:

- `year` إلى `academic_year`.
- `weights.{school, aptitude, achievement}` إلى حقول الأوزان.
- `program` و`major` إلى `program_name`.
- `body` إلى `content`.
- `percentage` و`"96.4%"` إلى `ratio`.
- `source` إذا كان نصًا يُقرأ كرابط.
- `about` إلى `description`.

لم أطّلع على ملف v1 حقيقي من النسخة السابقة. لذلك ارفع ملفًا قديمًا واحدًا وراجع معاينته قبل الاعتماد عليه.

## برومبت الاستخراج (انسخه كما هو)

```text
أنت تستخرج بيانات جامعة سعودية واحدة من ملف PDF مرفق لمنصة «مُوجّه».

القواعد:
1. اعتمد على الملف المرفق فقط. لا تكمل من معرفتك، ولا تخترع روابط أو سنوات أو أرقامًا أو أوزانًا.
2. إذا احتوى الملف أكثر من جامعة ولم أحدد المقصودة، توقف واسألني عنها.
3. راجع كل صفحات الجامعة، لا صفحة التخصصات وحدها: النبذة، الفروع، التصنيف، التنافسية، التوظيف، شروط القبول ومساراته، التخصصات، النسب السابقة، السكن، البيئة والمميزات، السلبيات، التواصل، المنصات، الرسوم.
4. التصنيف ونسبة التوظيف: اكتب الجهة والسنة داخل النص إن وردتا. التقدير أو الرأي غير الرسمي اذكره كما هو بصيغته.
5. مسارات القبول نوعان:
   - موزون: أوزان رقمية صريحة مجموعها 100.
   - نصي (SAT، أولمبياد، قبول بشروط): أوزانه 0 0 0، والشروط في requirements، وacademic_year فارغ إن لم تُذكر السنة.
6. النسب السابقة تحتاج رقمًا وسنة وتخصصًا. إن غابت السنة ضعها في uncertain، لا في cutoffs.
7. كل سجل يحمل "page" برقم صفحة الـPDF.
8. كل معلومة غير مؤكدة أو غير واضحة تُضاف إلى uncertain، أو يُضاف للسجل "uncertain": true. لا تضعها كحقيقة.
9. لا تضف الحقول id أو university_id أو published أو أي حقل صلاحيات.
10. لا تجعل اسم الكلية أو الدرجة «غير محدد»؛ اتركه فارغًا إن لم يُذكر.
11. أخرج JSON صالحًا واحدًا فقط بالصيغة التالية، دون أي شرح قبله أو بعده:

{"format":"muwajjah-university-v2","university":{...},"programs":[...],"tracks":[...],"sections":[...],"cutoffs":[...],"source":{"url":""},"uncertain":[...]}

حقول university: name, city, region, type, description, housing_status (available|limited|unavailable|unknown), housing_note, website_url.
حقول programs: name, college, degree, gender, campus, admission_route, page.
حقول tracks: name, academic_year, gender, school_weight, aptitude_weight, achievement_weight, requirements, page.
حقول sections: title, content, page. استخدم عناوين مثل: «الفروع والمقرات»، «التصنيف»، «التنافسية»، «التوظيف بعد التخرج»، «شروط القبول»، «البيئة الجامعية والمميزات»، «أبرز السلبيات»، «التواصل مع الجامعة»، «منصات التواصل»، «الرسوم الدراسية».
حقول cutoffs: program_name, academic_year, gender, ratio, page.
```
