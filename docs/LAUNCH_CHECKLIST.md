# قائمة ما قبل الإطلاق العام المجاني

## 1. البيانات والقاعدة
- [ ] خذ نسخة احتياطية كاملة من Supabase، وتأكد أنها ظاهرة في Backups أو أن ملف `pg_dump` يفتح عندك.
- [ ] شغّل `database/000_readonly_diagnostic.sql` واحفظ نتائجه.
- [ ] تأكد أن الدالة `guide_publish_university_with_content` موجودة (الاستعلام 2). إن لم تكن موجودة، فزر «نشر الجامعة ومحتواها» سيفشل برسالة «الميزة غير مفعّلة». لا تشغّل `schema.sql` كاملًا؛ اطلب migration محددًا.
- [ ] طبّق `001_student_features.sql` إن لم يكن مطبّقًا (الاستعلام 7).
- [ ] قرّر تطبيق `002` (المسارات النصية) و`003` (إصلاح التحليلات) بعد قراءة رأس كل ملف.
- [ ] راجع نسبًا قديمة نُظّمت تحت سنة لا يذكرها مصدرها، كحالة جودة بيانات لا كإذن بالحذف.

## 2. الأدوار والحسابات
- [ ] حساب مالك واحد مفعّل. لا كلمة مرور مشتركة.
- [ ] جرّب مساهمًا تجريبيًا: يرى جامعته فقط، ولا يعدّل غيرها.
- [ ] جرّب طالبين: كل منهما لا يرى مفضلة الآخر ولا نتائجه.

## 3. الإطلاق الصامت
- [ ] في «بلس والوصول»: النسب السابقة إما مخفية، أو «بلس» مع **عرض مطفأ**. المقارنة مخفية أو مجانية حسب قرارك.
- [ ] افتح الموقع في نافذة خاصة بلا دخول: لا قفل، ولا «بلس»، ولا «اشتراكي».

## 4. المصادقة والنطاق
- [ ] Supabase ← Authentication ← URL Configuration: اضبط Site URL على النطاق النهائي.
- [ ] Redirect URLs: أضف `/auth/callback` و`/auth/reset` و`/admin/callback` و`/admin/reset` على النطاق النهائي.
- [ ] مزود البريد (SMTP) وحدوده: راجعها قبل فتح التسجيل الواسع. لا تُلغِ تأكيد البريد لتجاوز `email rate limit exceeded`.
- [ ] Google: فعّل المزود في Supabase، وأضف Callback إلى عميل Google، ثم فعّل ظهور الزر من الإدارة. السر يبقى في Supabase فقط.
- [ ] جرّب في المتصفح نفسه: تسجيل، ثم تأكيد، ثم دخول، ثم خروج، ثم استعادة كلمة المرور. هذا شرط تدفق PKCE.

## 5. النشر
- [ ] ارفع `dist` (أو اربط المستودع بـNetlify: build `npm run build`، publish `dist`، Node 22).
- [ ] افتح مباشرة `/universities/<id>` و`/student/dashboard` و`/admin/login`، ثم حدّث الصفحة. يجب ألا يظهر 404.
- [ ] لا تترك رابط معاينة عامًا لنسخة تجريبية متصلة بالقاعدة نفسها.

## 6. الخصوصية والمراقبة
- [ ] بيان خصوصية يوضح ما يُحفظ فعلًا: البريد والاسم، المفضلة، نتائج الموزونة، وتحليلات مجمعة يومية بلا هوية. لا تعلن امتثالًا قانونيًا لم تتحقق منه.
- [ ] راجع لوحة Supabase أسبوعيًا: حجم القاعدة، MAU، ونقل البيانات. عتبتاك: 300 MB مراجعة، و400 MB إجراء.

## مؤجل لمرحلة بلس (ليس شرطًا للإطلاق المجاني)
- ربط الدفع (زد أو غيره). يحتاج دالة خادم تتحقق من إشعار الدفع، وتمنع التفعيل المكرر، وتعالج الاسترجاع. لا يُمنح بلس من المتصفح.
- صفحة الأسعار وعرض الاشتراك.
- الترتيب الشخصي والحجوزات: غير مبنية، وتبقى أفكارًا.
